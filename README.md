# enigmatik — vidéos TikTok d'énigmes

Une vidéo par jour à 19 h sur TikTok (@enigmatik.1) : 5 énigmes de plus en plus dures.

- `videos/` : les vidéos finales (lues par Buffer via leur lien public)
- `contenu/` : le texte de chaque vidéo (JSON)
- `pipeline/` : le programme qui fabrique les vidéos (voix IA Kokoro, police Montserrat sous licence OFL, musique originale)
- `historique.json` : toutes les énigmes déjà publiées (anti-doublons)
- `AUTOMATISATION.md` : la procédure suivie chaque jour
